# 官网设计与验收记录 · 2026-11-05

目标是让第一次接触项目的人理解豆梨、体验一个例子，并找到可运行的代码。官网设计、对话和生活手记均为项目原创展示；示例不是一次真实模型调用。

对照的是作品中的具体设计问题：参考 [Awwwards 展示的 Oura Ring](https://www.awwwards.com/sites/oura-ring) 的产品首屏、移动版和场景导览；参照 [Webby 最佳用户界面的获奖案例](https://winners.webbyawards.com/winners/websites-and-mobile-sites/features-design/best-user-interface?sort=0)，看访客能否辨认并完成下一步；参考 [FWA 对 Bruno's Portfolio 和 Sleep Well Creative 的评述](https://thefwa.com/FWA25/RobFWA.html)，看交互和动作是否服务于内容。这里记录的是本项目的设计判断，不是奖项评审或同等级认证。

| 维度 | 检查与修订 |
| --- | --- |
| Typography 字体 | 首屏中文标题与英文标注形成两级层次；首轮辅助文字偏小，增大正文、案例说明与原话来源字号，取消硬编码的正文换行。 |
| Whitespace 留白 | 首屏使用双栏，手机改为纵向；压缩超宽桌面首屏高度，让页脚式章节导航更早出现。 |
| Visual hierarchy 层次 | 首屏入口分别带到产品示例与源代码；将原装饰文字栏改为可点击的语音、记忆和实现目录。 |
| Color 色彩 | 延续梨绿标志，纸色背景、深绿记忆段、梨黄色上手段形成阅读节奏；加深浅色辅助文本。 |
| Motion 动作 | 品牌插画轻微呼吸与眨眼；可在首屏暂停。模拟系统减少动态效果后，按钮显示「已减少动效」，不再允许强制开启。 |
| Micro-interaction 反馈 | 检查预设对话切换、展开原话、FAQ、复制成功反馈、手机菜单收起与 Escape 操作；原话展开时纸张回正，便于阅读。 |
| Responsive 响应式 | 首轮发现旋转轨道超出窄屏边界；限定装饰区域并允许网格子元素缩小。最终在 320、390、768、1024、1440 CSS px 视口逐一核对，文档滚动宽度与布局宽度差均为 0。 |
| Originality 原创性 | 梨形角色、对话场景和纸质手记分别表达声音、记忆、原话；增加可展开的板端 422 包对照实验，将架构介绍连接到项目自己的工程证据。 |

验证在 Windows Chrome 进行，手机尺寸使用浏览器视口模拟，不等于 iOS/Android 真机验收。已检查真实 DOM 与关键页面截图；没有做屏幕阅读器真人测试、全浏览器兼容认证或正式第三方可访问性审计。官网不加载第三方字体、图片、分析脚本或 SDK，无额外 npm 依赖。

`npm run site:check` 检查静态资源、锚点、文档链接、公开文件类型与体积。主应用未修改；既有应用测试不代替官网的浏览器与公网验收。
