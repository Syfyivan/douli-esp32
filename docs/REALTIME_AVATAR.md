# Simli 实时形象

在「设置 → 实时形象」保存 Simli API Key 和 Face ID。可刷新账户形象，或先使用内置示例 Tina / Laila / Kate。侧栏「视频通话」是独立页面，点击「开始通话」连接；对话记录里的视频入口也会进入该页面。麦克风权限只在通话时请求，离开视频页会结束通话并释放媒体资源。

Tina / Kate 使用[官方当前示例列表](https://docs.simli.com/api-reference/preset-faces)中的 Trinity-2 形象，Laila 保留原有示例。新安装默认选择新版 Tina；现有自定义形象不会自动迁移。Trinity-2 仍使用 Compose `apiVersion: "v2"` 和相同 PCM 协议，不需要改成 v3/v4。

视频通话控制区的「音量」可在 0–400% 之间调整，首次默认 200%，选择保存在当前浏览器中；0% 立即静音。只调整 Simli 返回声音的本地播放增益，不改变麦克风、TTS 音色或发往 Simli 的音频。Web Audio 在放大后压缩过高峰值以减少破音，原始媒体元素保持静音以避免重复播放。打断使用独立的播放开关立即静音，调节音量不会重新放出已打断的声音；结束通话断开音频节点。

主界面只显示形象、通话状态、麦克风、挂断和音量。字幕、暂停、手动结束一句话、打断放在「更多」中。视频通话从自己的新会话开始，历史内容在「对话记录」查看，不再把视频挤在消息列表里。

照片创建入口接受小于 5 MB、至少 512 × 512 的 PNG / JPEG / WebP。使用单人正面照，头部至少占高度的 15%。勾选授权后上传，创建 Trinity-1 形象，占用账户的形象名额。完成后点击「使用这个形象」，不会自动覆盖当前选择。上传超时的结果可能不确定，应在 Simli 控制台核对，避免重复消耗名额。

现有 ASR、聊天模型、个人档案和 TTS 保持原有链路。Simli 只接收 TTS 回答的 PCM16LE、单声道、16 kHz 音频，通过 WebRTC 返回同步音视频。照片不落盘，云端形象由 Simli 保存。长期 API Key 在本地 Store 加密保存，前端仅获得短期 session token 和 ICE 凭证。

视频客户端在语音 hello 中声明 `features.avatar_audio: true`。服务端只对浏览器接受该特性，保持驱动 PCM 的原始幅度，通过每句 `tts.sentence_start.playback_gain` 单独传递设备及夜间播放音量；前端在 Simli 返回音频后乘以此值和用户音量。级联 TTS 与原生实时语音两条路径一致，普通浏览器语音及音箱保留原来的 PCM 音量处理。缺少该字段时前端使用 1，兼容旧服务。

本机管理服务提供 `/api/avatar/faces`、`/api/avatar/session` 和 `/api/avatar/generation`。照片创建直接调用 `/faces/trinity?gsVersion=GSA_1.0`，由 Simli 在未提供 target-ratio 时完成预处理。服务端固定上游主机，不接收用户指定的外部地址。

浏览器使用 Simli Compose P2P 协议：`wss://api.simli.ai/compose/webrtc/p2p`。官方文档页面名是 `peer_to_peer`，其同名 WebSocket 路径实测返回 403；SDK 使用的 `/p2p` 实测可连接。桌面 CSP 只新增该主机的 WebSocket 权限。

打断会立即静音并发送 SKIP；结束会关闭音视频、麦克风和两条连接。视频通话的暂停会终止当前回答，再暂停收音。实时时钟无法恢复旧的视频片段，因此视频模式不提供独立的「暂停播放」。视频连接失败会结束通话，可再点击「电脑语音」继续纯语音。

Simli 没有逐句实际播放时长回执，视频通话不会将接收 ACK 冒充已播放确认，历史中的播放结果保持 unverified。当前每次视频连接最长 30 分钟，连续 2 分钟没有回答音频会被上游关闭。应在不用时主动结束通话，静默也可能计入套餐连接时长。

代码测试覆盖：凭证加密与脱敏、空密钥保存语义、图片上游协议、重复上传抑制、错误脱敏、打断时丢弃旧音频、关闭时清理资源。真实视频、音画同步、中文口型、插话体验需要使用已登录浏览器和实际服务另行验收；协议测试不能代替这些验收，也不证明 ESP32 或 Android 视频支持。

参考：[创建形象](https://docs.simli.com/api-reference/create-avatar)、[照片生成](https://docs.simli.com/api-reference/generate-trinity-face)、[P2P 协议](https://docs.simli.com/api-reference/websockets/peer_to_peer)、[JavaScript SDK](https://docs.simli.com/api-reference/javascript)。
