# 更新日志

## 2026-11-04 — 向量索引一致性与生活记录校验

- 修复向量索引等待模型返回时，后续批次仍发送已删除或已修改记录的旧文本；更新后的记录留到下一轮索引。
- 关闭语义检索或更换向量模型、服务地址、凭据后，旧任务停止发送后续批次并丢弃晚到结果；取消任务后不再写入结果。已发送给模型的文本无法撤回。
- 索引复用预编译 SQL 和内容哈希，查询现有索引时只读取模型标识与哈希，避免读取不需要的完整向量。未进行性能基准测试，不声明具体提速比例。
- 生活记录拒绝会被自动解释为次日的 `24:00`，保留合法闰日与显式时区；主题与类型筛选拒绝异常类型，返回 400。
- 无新增依赖、数据库迁移或设置变更。实现修改位于 `server/memory-search.mjs` 与 `server/diary.mjs`，配套测试与使用说明同步更新。

验证：完整 `npm test` **304/304 通过**（新增 9 项）；前端构建、修改过的服务模块语法检查和 `git diff --check` 通过。构建仍有 lucide-react 的 `use client` 提示。独立后台使用隔离的虚构数据库，在启动 shell 退出后验证健康接口、前端资源、无效输入、记录新增/修订/筛选/移除及旧版本冲突，并正常关闭验收进程。未验证真实模型质量、ESP32 硬件、原生客户端或跨设备行为；未制作安装包、触发发布或更新用户运行中的服务。

## 2026-10-26 — 本地生活记录与主题分类

基于 `16a6795` 开发，开始前已执行 `git pull --ff-only origin main`，当时远端无新增提交。

### 用户可见变化

- 「我的资料 → 近期经历」升级为「生活记录」；新增按日期、主题、经历/计划筛选，以及手动补充、修订、移除和原话追溯。
- 区分自动整理、人工修订和手动记录，保留原有按天/对话回顾；关闭自动提取后，已保存条目的回顾仍在本地重建，无需模型调用。
- 仍使用电脑本地 SQLite；健康资料沿用独立加密流程，没有新增云端数据库或依赖。

### 协作开发与升级注意

- `server/diary.mjs` 管理输入校验和生活记录读写；`web/diary.jsx` 为新界面，原记忆与摘要页继续复用。
- `memory_episodes` 新增 `topics/origin/revision/deleted`，迁移保留旧记录；旧条目默认未分类，升级不会批量调用模型。
- 手动修订/移除后，同一原话的经历暂停自动重写，避免晚到模型结果覆盖或恢复。原话更正/删除仍会让关联整理失效。
- 更改记录立即使受影响的摘要、向量失效；版本冲突返回 409。原始聊天保留，移除生活记录不等于删除原话。
- 同步两端需升级到相同版本；旧客户端无法使用新增结构。回退需恢复升级前数据库备份，不能仅切回旧代码。
- 接口字段、存储边界及验证命令见 [本地生活记录](LIFE_RECORDS.md)。
