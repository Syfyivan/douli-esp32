## 同意证据和文案发布机制

每份法律文本保存 documentId、version、contentHash、publishedAt、effectiveAt 和适用功能。用户回执记录账号、准确文本版本及哈希、确认动作、时间和必要环境证据；不同用途的 consentPurpose 分开，记录撤回时间和服务端生效结果。避免为留证无差别保存指纹或不必要设备信息。

API 发放通话凭证前校验：账号、成年资格、适用协议版本、必要授权、供应商可用、风险状态及额度。付费功能另行校验商品和订单规则快照。重要协议变更、供应商变化和处理目的变化不能只更新网页后假定旧授权继续有效。

同意撤回要传播到正在进行的通话、后台队列及供应商处理；例如关闭摄像头立即停止采集、撤回形象或声音授权停止对应生成和音色调用，关闭记忆取消未执行提取。撤回版本覆盖迟到回调和缓存，避免角色被异步任务复活。文案每项承诺都对应实际测试，不通过的承诺必须改实现或改文案，不能用隐藏脚注掩盖。

发布前复核：真实主体与联系方式、适用备案信息、年龄及应急措施、全部数据接收方、各类保存期限、实际收费退款、素材授权、AI 标识、退出与注销、无夸大免责声明。监管资料、代码实现、供应商合同和用户可见文本须互相一致。
