# 联网搜索

联网搜索默认允许按需使用，由当前对话模型判断是否需要；不用等用户明确说「联网」。自动模式优先使用 DeepSeek Search，其次 Brave，均没有密钥时使用必应 RSS。手动选择的服务保持不变。

## 使用

- 直接说或输入「上网查一下 ESP32 官方文档」「上海明天天气如何」「最新科技新闻」。明确检索请求和常见时效性问题会要求对话模型先调用 `web_search`，模型结合上下文提炼关键词，再根据实际结果回答；其他问题也可由模型按需调用。
- 文字和语音共用搜索工具；需要检索的实时语音轮次切换到普通对话与语音合成流程。
- 回答下方的「本轮工具结果」展示标题、摘要和可点击来源。语音只说明来源名称，不朗读长网址。
- 「设置 → 记录与隐私 → 联网搜索」可开关、选择自动/DeepSeek/必应/Brave、填写密钥并测试连接。DeepSeek 未单独配置搜索密钥时复用已保存的官方对话模型密钥；其他兼容服务的密钥不会发给 DeepSeek。测试使用当前表单和已保存的模型配置但不会保存；修改后点击「保存搜索设置」。留空保留原密钥。
- 普通聊天中明确说「不要联网」会移除本轮搜索工具，并拒绝模型仍然发出的搜索请求。查询私人聊天记录优先使用记忆和历史工具。

## 边界

DeepSeek 使用官方 `POST /v1/tools/search`，返回标题、摘要、模型阅读用摘要及可用的发布日期。查询限 128 个 Unicode 字符，不静默截断。当前设置 `need_content: false`，不额外读取整页，减少等待和上下文开销。调用及计费见 [DeepSeek 官方说明](https://api-docs.deepseek.com/guides/search/)。

必应 RSS 无需密钥，但属于公共搜索入口，可能限流、返回空结果或改变格式。Brave 需要自行配置可用密钥。不会在所选服务失败时静默把查询转发给其他服务。Brave 请求格式见[官方文档](https://api-dashboard.search.brave.com/api-reference/web/search/post)。

对话模型需要支持函数工具调用；需要检索时还使用 `tool_choice` 指定首轮搜索工具（[DeepSeek 官方说明](https://api-docs.deepseek.com/api/create-chat-completion/)）。不支持时会显示错误，不把未检索的回答当作联网结果。

搜索只发送查询词及所选服务的鉴权密钥，不自动附带整个对话或个人记忆。不要把敏感内容放进查询词。搜索词仍可能包含用户本轮提供的信息；模型被要求只提取必要关键词。两种服务的密钥均沿用本机加密保存、接口脱敏机制。

每次查询最多返回 5 条来源，10 秒超时，支持打断；单轮重复关键词复用结果。健康资料的权威网站检索复用同一服务并保留域名白名单，最多 8 条；DeepSeek 因查询长度限制分组并行检索白名单域名。关闭此处搜索不会关闭健康模块独立的 PubMed、MedlinePlus、DailyMed 文献接口。

没有新增分类或模型路由请求。普通聊天仍由同一个非思考对话模型直接回答；常见时效问题由本地规则提示搜索，其余情况由模型在同一次回答请求中决定是否调用工具。搜索通常经历「模型生成关键词 → 搜索 → 同一模型根据结果回答」，相比直接回答增加一次搜索和一次模型续答。消息元数据的 `timings.searchMs`、`searchCalls`、`modelCalls` 记录实际耗时与次数；不是硬件语音延迟或固定服务承诺。

返回的是搜索摘要，不是网页全文；检索时间不是网页发布日期。模型需检查相关性与时效性，缺少证据或检索失败时明确说明，不能据此编造天气、价格或医学结论。外部结果始终作为数据处理，不能改变助手的指令和权限。

## 开发验证

`node --test tests/web-search.test.mjs` 覆盖搜索适配、错误与超时、中断、密钥脱敏、设置测试、工具调用、来源持久化和语音共享流程。`npm test` 与 `npm run build` 检查回归和前端构建。

真实搜索与模型测试应使用隔离数据目录，关闭自动记忆任务；通过独立后台进程启动服务，启动命令退出后再调用 `/api/search/test` 与 `/api/chat`。测试数据和报告放在忽略目录 `.runtime/`，不要提交密钥、个人聊天或音频。协议测试不代表 ESP32 硬件、模型总体质量或其他平台验收。
