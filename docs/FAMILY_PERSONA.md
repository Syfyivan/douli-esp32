# 亲人照片与声音定制虚拟角色

日期：2026-10-25。属于 [完整产品方案](COMPANION_PRODUCT_PLAN.md) 的正式交付范围；本文件定义尚待实现的能力，不表示已经完成声音克隆、授权审核或商用接入。

## 用户体验与完整流程

用户可以用亲人的照片和合法持有、获准处理的声音素材，创建带有相应外观、音色、称呼和表达习惯的私有 AI 角色。既支持在世成年亲人，也包含经专门审查的已故成年亲人纪念场景。成年用户资格与被复刻者的权利状态分别核验；不把“成年用户”当作可以任意复刻他人的条件。

创建流程：选择在世/已故及人物关系 → 本地选择和预览素材 → 权利与用途核验 → 受控上传 → 图片与声音质检 → 分别生成形象及音色 → 带 AI 标识试听预览 → 确认采用 → 开始视频通话。付费生成前展示实际费用、可重试次数及失败退款规则。授权未通过时不把素材提交给生成服务商。

支持单张或多张照片选择主形象；声音来源包含现场录制、合法历史录音或从合法视频中选出的单人声音。视频只提取经选择的目标片段，不将整段家庭视频或背景中其他人的谈话默认上传。播放、裁剪和素材质量提示尽量在本地完成；上传后转码与解码在隔离环境运行，限制文件大小、时长及资源占用。

声音质检包含有效人声、单一说话人、噪声、削波、混响、音乐和语种；照片质检包含清晰度、人物数量、遮挡和生成服务要求。素材不足时解释需要补什么；不能承诺几秒录音或一张照片就能完整恢复声音、人格或记忆。采样长度与格式按最终服务商要求配置，不把某个接口建议写成全产品通用保证。[声音复刻接入示例](https://docs.volcengine.com/docs/real_time_communication/Soundreproduction?lang=en)

预览包含中性固定短句、用户允许范围内的自定义短句和短视频。用户可选择重新采样、调整语速、重新生成或放弃；不把预设音色悄悄当作亲人的克隆结果。口音和情绪还原属于实际验收项，不能用“相似度 99%”等无依据数字宣传。

## 授权与受理规则

| 情形 | 产品处理 |
|---|---|
| 在世、能够自主授权的成年亲人 | 本人知情后分别确认肖像、声音复刻、必要敏感信息处理和可访问账号；平台核验授权人与素材主体的关系，家属单方勾选不够 |
| 在世但不能自主有效授权 | 转人工和法律审查，核验代理资格、权限及必要性，不自动接受普通亲属代签 |
| 已故成年亲人 | 核验素材来源、相关亲属身份与关系、必要死亡信息、生前意愿及现有许可；逐案评估相关权益和争议，供应商同时须允许该用途 |
| 无有效授权、存在本人反对或权利争议 | 不启动生成；已启用角色有争议时及时限制并调查，保留申诉和必要证据 |
| 未成年人使用者 | 禁止使用虚拟亲属功能；监护人同意不能作为开放此功能的依据 |
| 未成年人作为被复刻对象 | 延续本产品只制作成年人物角色的范围，不受理；这是产品边界，不声称法律全面禁止所有此类技术 |

在世本人的声音受人格权益保护；照片持有权、摄影作品权利、肖像及声音许可需要分别核对。深度合成人脸/人声编辑涉及对被编辑个人的告知和单独同意。[民法典第一千零一十八至一千零二十三条](https://www.cac.gov.cn/2020-06/01/c_15925617772683193.htm)、[深度合成管理规定第十四条](https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm)

已故场景不存在一个“家属同意即当然合法”的统一结论。民法典对死者相关人格利益给予保护，并规定有关近亲属的救济权；这不等于近亲属继承了其人格权、或任意一名家属获得排他商业授权。生前明确反对时不受理；缺乏生前明确许可的，结合用途、授权链、相关亲属权益、素材权利及服务商合同作个案法律审查，不能伪造本人同意。亲属存在实质争议时先暂停生成与使用。[民法典第九百九十二至九百九十四条](https://www.cac.gov.cn/2020-06/01/c_15925617772683193.htm)

已故审查仅收集证明必要事实的最少材料，允许遮盖无关证件字段，必要时接受能证明同一事实的替代材料。不能把完整户口簿、死亡证明和家庭关系档案作为无差别默认收集项。具体证据清单及法律依据由运营法律负责人确定，核查结果与原件分开保留。

向未成年人提供虚拟亲属服务是现行规定明确禁止的情形；服务端在角色创建、预览、媒体令牌发放、使用及共享访问各环节校验年龄资格。[拟人化互动服务管理暂行办法第十四条](https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm)

## 角色内容与记忆

形象、音色和角色资料分开：照片决定外观，声音素材用于音色构建，称呼、口头禅、语言习惯和共同经历由有权提供的资料补充。系统不能仅凭脸或声音推断其真实人生、性格、信仰或未说过的话。

每条回忆记录来源、提供者、原始日期及可见范围；区分亲人原话、用户回忆、推测和本次 AI 生成。无法核对的回忆不描述成既定事实，AI 回答不反写为亲人生前原话或共同经历。角色可采用已授权的称谓和语气，但在身份问题上如实说明是 AI。

通话画面持续标识“AI 定制角色”，纪念角色标识“AI 纪念角色”；首次使用和角色详情说明新生成的言语不代表本人真实意思。不得宣传复活、意识上传、与逝者真实通话，或让角色编造遗嘱、财产处置、授权承诺和遗愿。涉及这些问题可指向有来源的历史材料，但不能让模型作本人授权。

用户自己的聊天记忆与亲人素材库分开，跨角色共享须显式选择。默认只有创建者可访问；若授权允许指定成年家人共同使用，逐一邀请、核验并授权，素材许可共享不使成员私聊互通。权利人管理授权的入口也不自动获得用户私聊内容。

## 技术与供应商

    已核验照片 → 数字人生成任务 → 形象资产
    已核验声音 → 音色构建任务 → 私有音色资产
    有来源的角色资料 → 角色资料库 / 检索
    用户发言 → ASR → 对话与安全审核 → 私有音色 TTS → 数字人 → 实时音视频

用统一接口封装音色创建、状态查询、试听、合成、停止与删除。声音服务商与数字人服务商可以不同，但必须支持实际音频格式、采样率、流式传输及打断；将模型接口示例视为技术路径，不视为整条链路已验收。音色构建可能是特征提取、专属训练或适配，须按实际技术及合同告知。[声音复刻 API 文档](https://docs.volcengine.com/docs/DoubaoVoice/SoundReplicaAPI-V3?lang=zh)

采购约束：明确商用平台使用权、授权第三人复刻、已故场景政策、境内处理、样本与模型保留、是否可删除、失败计费及音色槽位复用规则。官方语音体验服务存在只允许本人声音、仅限体验等限制；不能拿体验协议证明本项目商业资格，也不能据此假定所有商用 API 都禁止亲人复刻。[官方体验服务规则](https://docs.volcengine.com/docs/DoubaoVoice/VolcanoEngine-SpeechModelExperienceServiceDisclaimerandServiceRulesDescription?lang=en)

专属样本仅用于经授权的角色资产构建，不进入通用训练或公共音色库。样本、声音特征、模型权重/适配文件、预览音频、头像资产和供应商编号均作为受控资产管理。不能只删除原始录音而仍允许旧音色继续合成。

数据至少包括：角色、人物状态、权利主体、授权凭证及期限、素材清单与指纹、生成任务、形象与音色版本、允许访问账号、争议、撤回及删除任务。每次合成同时校验用户、角色、资产归属、授权有效性和撤销版本；不接受前端直接传入任意供应商音色编号使用。

状态包括草稿、待授权、待审核、质检、生成、待预览、可用、受限、撤销中、删除中及完成。照片和音色任务独立幂等；任一失败不自动把另一项发布为完整角色。供应商超时返回结果不明时先查任务，防止重复扣费。授权撤销后的迟到成功回调不能重新启用角色，需立即进入资产清理。

音色编号/槽位不能在未确认清理及撤销旧缓存时交给其他用户；保留版本和删除回执，防止旧账号通过缓存使用新用户音色。角色授权变更或在世人物去世后，重新检查使用依据，不能自动继承原权限。

## 删除、费用与验收

权利人可经核验撤回，创建者可删除角色。立即停止新会话与新合成，取消队列及进行中的媒体，然后删除可控样本、预览、模型和供应商资产；展示实际处理状态及依法保留事项。原始声音档案若用户另行选择保留用于回听，必须单列用途与期限，不能默认变成长期录音仓库。

默认不提供克隆模型下载、开放音色 API 或以亲人身份拨打外部电话。授权范围内的生成片段导出需单独校验，保留 AI 标识；不能因为是私有角色就默认允许所有分享与商用。普通用户数据复制权与他人肖像声音许可分别处理。

价格区分照片生成、音色构建、可重试次数、资产维护及通话用量，生成前说明。审核不通过、生成失败、部分完成、用户不采用及撤回授权的退款规则写入订单；不能用“永远保留亲人”或丧失关系的威胁催续费。权利撤回不因购买套餐而失效，剩余服务依订单和法律结算。

验收同时覆盖照片质量、中文/方言及老旧录音的真实效果，原照片与新视频辨识度、声音相似度人评、端到端延迟、打断、记忆来源、年龄拦截、授权撤回竞态、角色共享隔离、供应商删除和账单。只用有权使用的素材；不使用未经同意的真实亲人资料作为测试集。

此功能需要在整体拟人化服务安全评估、深度合成评估、算法/应用材料、个人信息影响评估和供应商合同中如实描述，不能只在前端增加上传按钮。现阶段完成的是规格与协议更新，任何人物素材和音色均未上传或生成。
