# 豆梨 Electron 桌面端

桌面端复用现有 React 界面和 Node 服务，包含聊天、语音、记忆、健康资料、设备管理及同步设置。安装后的运行时由 Electron 自带，用户无需另外安装 Node.js。

## 桌面布局

界面按 `docs/designs/desktop-v3/` 实现，默认保留四个主入口：

- **对话记录**：自动打开最近一段记录，区分音箱、电脑语音和电脑文字，支持全文搜索、日期/来源筛选、导出和识别更正。电脑语音与继续文字对话收在底部，输入框按需展开。
- **我的助手**：集中调整称呼、语气、表达方式、开场白与夜间模式。右侧预览展示填写的开场白，不生成模拟回答。
- **我的资料**：包含「偏好与记忆」「近期经历」「健康资料」。新自动记忆仍需明确确认；经历按天或会话回顾并能跳回原对话。健康资料保留上传、原件查看、核对、编辑、趋势、导出和历史问答，不再单独发起健康咨询。
- **设置**：分为模型连接、声音与语音、个人词典、记录与隐私、同步与备份、功能显示、桌面偏好和运行记录。

「设备与家居」默认隐藏，可在「设置 → 功能显示」手动开启。隐藏只影响导航，音箱连接、对话记录和已有自动化继续运行。显示开关和默认首页保存于当前客户端的 localStorage（`douli.desktop.ui.v1`）；其他设备、浏览器和不同端口分别保存。业务资料和原有模型设置仍由本机服务管理。

## Windows 使用

- 安装版：运行 `release/desktop/Douli-Setup-0.1.0-x64.exe`，可选安装位置，并创建桌面及开始菜单快捷方式。
- 免安装版：运行 `release/desktop/Douli-Portable-0.1.0-x64.exe`。此版本免安装，但仍把数据保存在用户目录中。
- 解包目录：`release/desktop/win-unpacked/Douli.exe`；必须保留同目录下的资源和 DLL。
- 关闭窗口默认隐藏到系统托盘，本地服务和 ESP32 连接继续运行；点击托盘图标重新打开。隐藏或最小化窗口会结束电脑麦克风会话。
- 完全退出使用菜单「豆梨 → 退出」或托盘右键菜单。也可取消「关闭窗口后在托盘运行」。
- 「登录系统时启动」默认关闭，仅安装版提供，可在菜单主动启用。开机启动时隐藏到托盘。
- 导出沿用原页面功能，使用系统保存对话框；资料来源链接在默认浏览器打开。

首次打开时，如果 `127.0.0.1:8788` 已有兼容豆梨服务，桌面端连接它，保留原有数据及设备配对。菜单会标明「已连接现有服务」。退出桌面端不会停止这个外部服务，仍使用原启动器管理。

如果没有现有服务，桌面端启动内置 Node 子进程，管理端口为本机 8788、ESP32 端口为 8789。退出时等待数据库和服务关闭。遇到端口冲突、服务崩溃或持续连接中断，会显示恢复页，可查看日志或重新连接。不会终止占用端口的其他程序。

桌面端每 10 秒检查一次本机服务，单次请求最多等待 5 秒。短暂失败保留当前页面，连续 3 次失败才显示恢复页；恢复页仍继续检查，服务恢复后自动重新加载界面。日志记录 HTTP 状态、超时或拒绝连接等具体原因。内置服务进程确实退出时直接提示，可手动重新启动。

「重新连接」会复用仍在运行的内置服务，不会为了刷新连接而重启它。若此前连接的是外部启动器管理的服务，重连只等待这个服务恢复，不会趁端口暂时空闲另起一个使用不同数据目录的后台。外部服务需要由原启动器重新启动。

## 数据与日志

2026-10-16 连接恢复修复：此前单次检查失败即切到错误页，并因为存在错误信息而停止后续检测；后台恢复后界面仍停在错误页。新版本加入连续失败判定、恢复页持续检测和外部服务归属保护。此项属于 Electron 主进程更新，需要完全退出旧版（Ctrl+Q）再打开新版；只刷新网页不会替换主进程代码。

- Windows 桌面配置和日志：`%APPDATA%/Douli/desktop.json`、`%APPDATA%/Douli/logs/desktop.log`。
- 新安装默认数据：`%APPDATA%/Douli/data`；应用更新、重新安装不以安装目录覆盖数据。
- 源码运行默认沿用项目 `.data`，连接现有后台时则使用那个后台的数据。
- 自行管理服务时，菜单提供「打开数据目录」和「选择数据目录并重启」。连接外部服务时这两项禁用，避免把桌面端默认目录误认为正在使用的数据目录。
- 数据库 `douli.sqlite` 与加密密钥 `local.key` 必须一起备份。迁移时先退出相关服务，再复制整个数据目录，避免复制正在写入的 SQLite 文件。
- 可通过 `DOULI_DATA_DIR` 指定数据位置；`DOULI_PORT`、`DOULI_DEVICE_PORT`、`DOULI_DEVICE_HOST` 可配置端口和设备监听地址。桌面端自己的 HTTP 和语音来源校验同步使用管理端口。
- 同一数据目录只应由一个后台进程管理。桌面版不会自动复制浏览器、安卓或其他电脑的数据，跨设备同步继续通过现有同步页配置。

## 开发与构建

需要 Node.js 22.13+ 和 npm，首次安装/启动需要下载 Electron。图标沿用现有安卓矢量，源文件为 `desktop/assets/icon.svg`，Windows 下可用 `scripts/generate-desktop-icon.ps1` 重新生成 PNG/ICO。

```powershell
npm ci
npm run desktop          # 构建页面并打开开发版
npm run desktop:pack     # 构建当前平台的应用目录
npm run desktop:dist     # Windows x64 安装版及免安装版，不发布
npm run desktop:start    # 已构建页面的开发版，脱离启动终端独立运行
npm run desktop:start:packaged  # 独立运行 Windows 解包应用
```

`desktop:start` 返回进程 ID 后启动终端即可退出；应再检查窗口和服务。可用 `DOULI_DESKTOP_PROFILE` 为开发或验收指定独立的桌面配置目录。

已有应用正在运行时，可将新构建输出到另一个目录，避免覆盖被使用的文件。本次 UI 更新输出为 `release/desktop-ui-v3/`。通过环境变量 `DOULI_DESKTOP_BUILD_DIR=release/desktop-ui-v3` 可让 `desktop:start:packaged`、`desktop:check:packaged` 与 `--portable` 检查使用该目录。

构建采用显式代码目录列表，只包含 `desktop/`、`server/`、`dist/`、`licenses/` 和生产依赖；不会收集 `.data`、`.runtime`、音频、API 密钥或设备配对凭证。Electron 与 Chromium 随分发附带的许可文件应保留。配置中没有发布地址，构建命令禁止自动发布。
